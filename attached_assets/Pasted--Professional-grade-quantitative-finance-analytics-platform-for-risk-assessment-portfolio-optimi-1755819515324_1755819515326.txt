> **Professional-grade quantitative finance analytics platform for risk assessment, portfolio optimization, and derivatives pricing**

## 🎯 Why I Built This

I was curious about how investment banks actually calculate risk and price options. Rather than just reading about financial theory, I decided to build a working implementation that demonstrates these concepts in practice.

**Background:** Drawing from my experience in forex trading and personal investments, I researched standard industry models, learned the underlying mathematics, and created this full-stack platform that bridges academic theory with practical application.

**Technical Excellence:** Built with institutional-grade standards, featuring real-time market data integration, comprehensive database persistence, and professional export capabilities.

## ✨ Features

### 📈 Advanced Risk Analytics
- **Value at Risk (VaR)** calculations at 95% & 99% confidence intervals
- **Conditional VaR** for tail risk assessment in extreme market scenarios
- **Sharpe Ratio** analysis for risk-adjusted return evaluation
- **Maximum Drawdown** measurement for peak-to-trough decline analysis
- **Monte Carlo Simulation** for probabilistic price forecasting
- **Distribution Analysis** including skewness and kurtosis metrics

### 💼 Modern Portfolio Theory Implementation
- **Efficient Frontier** visualization showing optimal risk-return combinations
- **Mean-Variance Optimization** using mathematical portfolio construction
- **Sharpe Ratio Maximization** for best risk-adjusted portfolio allocation
- **Minimum Volatility** portfolios for conservative risk management
- **Correlation Analysis** with interactive asset relationship heatmaps

### 🔄 Pairs Trading & Statistical Arbitrage
- **Cointegration Testing** using Engle-Granger methodology
- **Hedge Ratio Calculation** via OLS regression analysis
- **Z-Score Monitoring** for real-time spread analysis
- **Automated Signal Generation** for entry and exit points
- **Statistical Significance** assessment with p-value analysis

### 🎯 Black-Scholes Options Pricing
- **Complete Option Valuation** for both calls and puts
- **Full Greeks Calculation** (Delta, Gamma, Theta, Vega, Rho)
- **Sensitivity Analysis** for parameter impact assessment
- **Time Decay Visualization** for theta exposure over time
- **Volatility Impact Analysis** for vega sensitivity

### 🗄️ Enterprise Data Management
- **PostgreSQL Integration** for persistent analytics storage
- **Professional Export Capabilities** (PDF reports, Excel workbooks, CSV data)
- **Historical Analysis Tracking** with comprehensive audit trails
- **Real-time Market Data** via Yahoo Finance API integration
